## Patterns to Avoid
- Shopping carts / e-commerce stores
- Basic CRUD (notes, todos, kanban)
- Game demos (maze, puzzle)
- Restaurant / hotel / flight booking
- Simple form filling

## Gap Analysis
Most apps are either:
1. CRUD wrappers (notes, tasks, calendar)
2. E-commerce (shopping, ordering)
3. Simple games
4. Booking flows

**What's missing:**
- Creative tools that combine human + agent in real-time
- Data exploration / analysis tools
- Collaborative visual canvases
- Developer tools
- Personal knowledge management
- Real-time collaboration beyond notes
- Educational / learning tools
- Wellness / lifestyle tools
