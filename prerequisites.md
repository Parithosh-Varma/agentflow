# Prerequisites

## Deployment Platforms
- [ ] Render — hosting the backend/server
- [ ] Cloudflare — DNS, CDN, or Workers
- [ ] Vercel — frontend hosting or serverless functions
- [ ] Shopify — product catalog or store integration
- [ ] Netlify — static site or serverless backend

## Development Environment
- [ ] Node.js v18+
- [ ] npm or pnpm
- [ ] Git installed and configured

## Browser & WebMCP
- [ ] Google Chrome installed
- [ ] WebMCP extension installed and enabled
- [ ] ChatGPT app access (for testing in-app browser)

## Project
- [ ] Repository cloned locally
- [ ] Dependencies installed (`npm install`)
- [ ] Environment variables configured (`.env`)

## Credentials & API Keys
- [ ] Render API key
- [ ] Cloudflare API token
- [ ] Vercel account linked
- [ ] Shopify store + API key / Admin access
- [ ] Netlify account linked
